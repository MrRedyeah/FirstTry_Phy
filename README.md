### 🖥️ GPU 环境检查

`check_gpu.py` 用于检查 Python、PyTorch 和 CUDA 环境，并通过简单训练验证 GPU 是否能够正常工作。

运行前需要准备相应依赖，以及支持 CUDA 的 NVIDIA GPU 环境。

```
python check_gpu.py
```

验证成功后，程序最后会输出：

```
PASS: GPU forward, backward, optimizer and NumPy conversion.
```

> 当前脚本要求 CUDA GPU 可用，详细环境配置说明将在后续补充。
